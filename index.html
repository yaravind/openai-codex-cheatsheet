Getting started

1) Keep asks specific

Include repo, goal, constraints, and expected output format for better results.

2) Iterate in small steps

Ask for a plan first, then implement in chunks and validate each change.

3) Validate before merge

Run tests/lint/build and review diffs before creating a pull request.
