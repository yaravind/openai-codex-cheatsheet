Overview

GA App

What is Codex App?

Codex is a cloud-based software engineering agent inside ChatGPT. It can read your codebase, write and edit code across multiple files, run tests, lint, and create pull requests — all in a sandboxed cloud environment.

GA CLI

What is Codex CLI?

Codex CLI is an open-source, lightweight coding agent that runs in your terminal. It reads, edits, and executes code in a sandboxed local environment with configurable approval modes and multi-provider support.

GA App

Availability

Available to ChatGPT Pro, Plus, Team, Enterprise, and Edu users with a connected GitHub account.

GA CLI

Requirements

Node.js ≥ 22, macOS or Linux (Windows via WSL2). Requires an API key from OpenAI (or compatible providers like Azure, Ollama, etc.).

App — Core Features

GA App

GitHub Integration

Connect any GitHub repository. Codex clones it into a sandboxed VM, works on your code, and pushes changes via branches or pull requests.

GA App

Multi-file Editing

Edit multiple files across your project simultaneously. Codex understands project structure and makes coordinated changes.

GA App

Run Tests & Linters

Codex can execute your project's test suite, linters, and build commands inside its sandbox to validate changes before creating PRs.

GA App

Pull Request Creation

Automatically creates a GitHub PR with a clear title, description, and clean diff. Review and merge when ready.

GA App

Parallel Tasks

Run multiple Codex tasks in parallel. Each gets its own sandboxed environment so they don't interfere with each other.

GA App

Sandboxed Cloud Environment

Each task runs in an isolated microVM with its own filesystem, network, and processes. Your local machine and production code are never at risk.

GA App

Internet Access in Sandbox

Sandboxed environments can install dependencies from package registries (npm, pip, etc.) with allow-listed network access.

GA App

Task History & Logs

Full trace of every task including terminal output, file diffs, and reasoning steps. Inspect what Codex did at every step.

Migrate between frameworks, upgrade dependencies, or convert code from one language/pattern to another.

App — Environment Setup

GA App

codex-setup-steps.yml

Define setup commands in .github/codex-setup-steps.yml (or copilot-setup-steps.yml) to install dependencies, configure toolchains, and prepare the sandbox before each task.

steps:
  - name: Install deps
    run: npm ci
  - name: Build
    run: npm run build
Preview App

AGENTS.md

Place an AGENTS.md file at the repo root or in subdirectories to give Codex persistent instructions — coding conventions, architecture rules, or review guidelines.

# AGENTS.md
- Use TypeScript strict mode
- Follow conventional commits
- Always run tests before PR
GA App

Custom Docker Images

Specify a custom container image in setup steps for specialized toolchains (Rust, Go, Java, etc.) beyond the default environment.

Preview App

Secrets & Env Variables

Pass repository secrets and environment variables to the sandbox so Codex can authenticate with private registries or services during setup.

App — Workflows

GA App

Task → Branch → PR

The standard workflow: describe a task → Codex creates a branch → makes changes → opens a PR for review. You remain in control of what gets merged.

GA App

Ask for a Plan First

Prefix your task with "create a plan" to get a step-by-step approach before any code changes. Review and approve before implementation.

Create a plan for adding OAuth login.

GA App

Iterative Refinement

Follow up on a task with corrections. Codex keeps context and can refine its changes based on your feedback.

Preview App

Issue-triggered Tasks

Assign a GitHub issue to Codex and it will automatically work on the task, referencing the issue in its PR.

GA App

Review Diff Before Merge

Always review the generated diff. Codex shows every file changed with clear before/after comparisons.

CLI — Install & Config

GA CLI

Install via npm

npm install -g @openai/codex
GA CLI

Set API Key

export OPENAI_API_KEY="sk-..."

Add to ~/.bashrc or ~/.zshrc for persistence.

GA CLI

Config File

Create ~/.codex/config.yaml for default settings.

model: o4-mini
approval_mode: suggest
providers:
  - name: openai
GA CLI

Project Instructions

Create ~/.codex/instructions.md or a project-local AGENTS.md to give Codex persistent context about coding standards and conventions.

CLI — Commands

GA CLI

Interactive Mode

codex

Launch interactive REPL in the current directory. Chat with Codex and approve changes one at a time.

GA CLI

One-shot Prompt

codex "Add input validation to the signup form"

Pass a task directly as an argument for non-interactive execution.

GA CLI

Choose Model

codex --model o4-mini "Explain this function"
codex --model o3 "Refactor auth module"
GA CLI

Full-auto Mode

codex --approval-mode full-auto "Fix all lint errors"

Automatically apply all changes and run commands without manual approval.

GA CLI

Quiet Mode

codex -q "What does this repo do?"

Suppress extra output. Great for piping results to other tools.

GA CLI

Pipe Context In

cat error.log | codex "Diagnose this error"
git diff | codex "Review this diff"

CLI — Approval Modes

GA CLI

🔒 Suggest

Default mode. Codex proposes changes but never writes to disk until you approve each one. Safest option.

codex --approval-mode suggest
GA CLI

✏️ Auto-edit

File edits are applied automatically. Shell commands still require approval. Good balance of speed and safety.

codex --approval-mode auto-edit
GA CLI

⚡ Full-auto

Both file edits and commands run automatically in the sandbox. Maximum speed, best for trusted tasks like linting or test generation.

codex --approval-mode full-auto

CLI — Features

GA CLI

Sandboxed Execution

All commands run in a network-disabled sandbox with directory-scoped file access. Codex cannot access files outside the project or make network calls.

GA CLI

Multi-provider Support

Works with OpenAI, Azure OpenAI, OpenRouter, Ollama, and any OpenAI-compatible API. Switch providers in config or via environment variables.

export OPENAI_BASE_URL="https://..."
GA CLI

File Watching & Context

Codex reads your project files to understand context. It tracks the current directory and respects .gitignore patterns.

Beta CLI

MCP Tool Integration

Connect Model Context Protocol (MCP) servers to give Codex CLI access to external tools like databases, APIs, and custom actions.

GA CLI

Open Source

Fully open source under the Apache 2.0 license. Inspect, fork, extend, or self-host as needed.

GA CLI

Multimodal Input

Pass images (screenshots, diagrams) alongside text prompts for visual context when describing UI changes or bugs.

Tips & Best Practices

GA App + CLI

Be Specific

Include the repo, goal, constraints, and expected output format. Vague prompts lead to vague results.

GA App + CLI

Iterate in Small Steps

Ask for a plan first, then implement in chunks. Validate each change before moving on.

GA App + CLI

Validate Before Merge

Run tests, lint, and build. Review every diff line. Check for unintended changes or regressions.

GA App

Use Setup Steps

Configure codex-setup-steps.yml so Codex's environment matches yours — same deps, same toolchain, same config.

GA CLI

Start with Suggest Mode

Use suggest mode until you're comfortable. Graduate to auto-edit or full-auto for trusted tasks.

GA App + CLI

Provide AGENTS.md

Write project-specific instructions in AGENTS.md. Include coding style, test patterns, architectural decisions, and review criteria.

GA CLI

Pipe In Context

Feed logs, errors, or diffs into Codex via stdin for richer context: cat error.log | codex "fix this"

GA App + CLI

One Task at a Time

Keep prompts focused on a single concern. Break large changes into smaller, reviewable units.
