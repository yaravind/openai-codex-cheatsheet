# openai-codex-cheatsheet

A fast, UX-focused cheatsheet site for Codex App and Codex CLI.

## Local preview

Open `index.html` in a browser.

## Deployment

The site is deployed with GitHub Actions via `.github/workflows/deploy-pages.yml`.

- Trigger: push to `main` or manual workflow dispatch
- Publish target: GitHub Pages
- Site URL: `https://yaravind.github.io/openai-codex-cheatsheet/`
